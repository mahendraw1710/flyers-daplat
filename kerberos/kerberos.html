Kerberos Login

Flow Handling Error Kerberos di HetuEngine

Error saat Test Connection atau Running Query.

Solusi
Modify Password FIM → Update DataArts → Jalankan Query Kembali
1

Modify Password FIM

  1. Buka Huawei Cloud Console
  2. Masuk ke Service MRS
  3. Pilih MRS-ETL-Spark
  4. Buka Access Manager
  5. Pilih Direct Connect
  6. Zoom Out ±80% (jika diperlukan)
  7. Klik Username di pojok kanan atas
  8. Pilih Change Password
  9. Input Current Password
  10. Input New Password
  11. Klik OK
💡Pastikan password FIM berhasil diperbarui sebelum lanjut ke DataArts.
2

Update Password pada Connection DataArts

  1. Buka Huawei Cloud Console
  2. Masuk ke Service DataArts
  3. Buka Management Center
  4. Search Connection
  5. Klik Edit
  6. Scroll ke bagian credential
  7. Update Username (CASE SENSITIVE)
  8. Update Password menggunakan Password FIM terbaru
  9. Test Connection
💡Jika Failed: cek username, password, dan typo. Jika Success: klik Save.
3

Jalankan Query Kembali di HetuEngine

Jalankan query kembali di HetuEngine.

✅ Jika SuccessIssue resolved.
⚠️ Jika FailedLanjutkan ke Troubleshooting di bawah.

Troubleshooting

  1. Re-check Password FIM Terbaru
  2. Verifikasi Username pada Connection MRS/DataArts
  3. Jalankan Test Connection DataArts Kembali
⚠️Jika masih gagal, eskalasi ke Tim Admin.
